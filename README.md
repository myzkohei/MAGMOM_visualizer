# MAGMOM Visualizer

MAGMOM Visualizer は、VASP計算で用いる POSCAR と INCAR を読み込み、各原子に設定された初期磁気モーメント MAGMOM を構造上で確認するための可視化ツールです。

VASPでは、原子座標は POSCAR、初期磁気モーメントは INCAR の MAGMOM にそれぞれ記述されます。そのため、複数元素を含む構造や大きなスーパーセルでは、どの原子にどの初期磁気モーメントを与えたかを確認しにくい場合があります。本ツールは、POSCAR と INCAR の対応関係を可視化することで、MAGMOM の設定ミスを確認しやすくすることを目的としています。

## Web app

以下のページから使用できます。

https://myzkohei.github.io/MAGMOM_visualizer/

## 主な機能

- POSCAR と INCAR を読み込み、原子ごとの MAGMOM を表示
- 原子種、原子番号、座標、初期磁気モーメントの対応を確認
- MAGMOM が設定された原子を視覚的に把握
- VASP計算前の入力ファイル確認に利用可能

## 想定する用途

- スピン分極DFT計算における MAGMOM 設定の確認
- 磁性元素を含む構造モデルの入力チェック
- スーパーセルや置換構造で、特定原子に意図した初期磁気モーメントが与えられているかの確認
- 学生や共同研究者との入力ファイル確認

## 使い方

1. Web app にアクセスします。
2. POSCAR ファイルをアップロードします。
3. INCAR ファイルをアップロードします。
4. 表示された原子リストまたは可視化結果から、各原子に対応する MAGMOM を確認します。

## 入力ファイル

本ツールは、VASPの入力ファイルである POSCAR と INCAR を対象としています。

- POSCAR: 原子種、原子数、格子定数、原子座標を読み取ります。
- INCAR: MAGMOM の値を読み取ります。

MAGMOM は、VASPで一般的に用いられる以下のような表記を想定しています。

```text
MAGMOM = 4*0 2*5 4*-5
```

この場合、POSCAR中の原子順に従って、各原子にMAGMOMの値が割り当てられます。

## 注意点

- MAGMOM の対応は、POSCAR中の原子順に基づいて解釈されます。
- POSCAR と INCAR の整合性が取れていない場合、意図しない対応として表示される可能性があります。
- 本ツールは入力ファイルの確認を補助するためのものであり、VASPの計算結果を解析するものではありません。

## 背景

VASPのスピン分極計算では、初期磁気モーメントの与え方によって収束先が変わる場合があります。特に、反強磁性配置、フェリ磁性配置、置換構造、欠陥構造などでは、どの原子に正または負の初期磁気モーメントを与えたかを事前に確認することが重要です。

MAGMOM Visualizer は、この確認作業を簡単に行うために作成したツールです。
